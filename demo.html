7 films · real work · ground truth checked

watch kn9t work▌

Seven screen recordings of kn9t doing actual work: a turn end to end, plugins created and hot-loaded, a playable plugin UI, a GitHub desk on live PRs, release notes read from real git history, a daily standup — and a bug desk that filed three real issues while being filmed.

100% real tool calls scripted model, zero API cost every film ground-truth checked pre-1.0

how to watch

Each film is a single unedited take. Under it: what the story is, and what is real (files really written, tools really executed, data really fetched). The model lines are scripted — the tool calls, the plugin protocol, the event log and the UI are the real thing. Every film carries its own proof: files present at cut, keys delivered to the TUI, transcript complete.

00 — making-of

One sequence file = one film

Every demo above was made by scripts/kn9t-demo-rec from a single .seq file — the typed choreography and the model script in one place. The recorder owns everything else: a sandbox home (your real ~/.kn9t and keys untouched), a deterministic terminal, capture cropped to the window (the desktop never appears), input injected at the pty (race-free — nothing can leak into your other windows), mp4 + gif + review frames + a timeline log.

pause / rate / type / say / send key SPEC click COL ROW sh CMD wait-file / wait-log model-script <<'JSON'

probes before the clap (keystrokes must reach the shell), a static-capture detector (aborts if the screen freezes), and a ground-truth report at cut: real files + keys delivered. Write your own: copy any scripts/demos/*.seq, edit, run.

real: the handshake on stdio, the registry rebuilt live, and a genuine rolled a d20 → 12 from the process that was just created.

07 — concrete

The bug desk — 3 real issues, filed on camera

49 s·triage ·mp4 ·gif ↗ ·issues ↗

triage files, labels and tracks real GitHub issues over gh, with a bug board in the TUI. The subject: the three bugs found while building these demos — filed with full repro steps, in one turn, as three parallel tool calls.

08 — the receipts

Found while filming. Filed by the film.

Making these demos pushed the tooling into the sharp edges of kn9t — and instead of staying in a notebook, the findings went through the product itself: the triage film files them as three real issues ↗, labelled and tracked on a board.

the three findings

#1 — approving with Always persists to config.toml; the config watcher reloads and reaps provider-plugin subprocesses mid-turn.

#2 — a non-interactive approval Deny never closes the turn (no turn_ended; the CLI waits forever).

#3 — a provider plugin dying mid-stream hangs the turn until the 600 s call timeout instead of failing fast.
